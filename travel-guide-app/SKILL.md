# 通用旅游攻略 App

把旅行资料转成旅途中能直接使用的工具。默认中文、手机优先；目的地、日期、风格和技术栈以用户要求为准。无需账户或跨设备同步时，优先采用静态 HTML/CSS/JavaScript + 本机存储 + PWA，避免引入无必要的服务端。

## 从资料到行程

先读取已有攻略、机票与酒店信息，仅询问影响路线的缺失条件：出发地、完整日期、同行人、预算和节奏。区分已确认订单、建议安排与待核实信息。不要推断酒店分店、套餐跨日有效性、航站楼或预约成功状态。

按完整日期组织每天的城市、活动、用餐、交通及住宿，预留移动、排队、安检和休息时间。跨午夜航班拆清日期；出发和抵达分别保存当地时间与 IANA 时区，不能仅用月/日或手机时区判断今天。跨年和旅程外新增日期应正常显示。

查询官方网站核实营业时间、闭馆、预约规则、票价和交通政策，并记录来源链接、核实日期及适用日期。无法核实的项明确标记，不把示例项目的旧攻略当作当前事实。

## 页面与交互

按需求采用“今日 / 行程 / 添加 / 美食 / 清单”导航：

- 今日：日期切换、下一站、时间线、完成进度、导航入口；旅行前后显示当前查看日期。
- 行程：航班分段、航站楼、酒店完整地址、入住退房及待确认事项，与时间线使用同一数据来源。
- 添加：景点、住宿、航班、餐厅、交通和其他；允许新增、修改和删除，删除提供撤销。滑动或长按只能作为快捷方式，保留可点击的编辑和删除按钮。
- 美食：地点、营业提醒、地图及已吃状态。
- 清单：预约、出发、退房、取行李及返程准备；支持 JSON 备份恢复和版本信息。

详情包含时间、地点、备注、官网/预约、电话和可选图片。地图使用准确地址或坐标并对查询参数编码；目的地未确认时标注“名称搜索”。使用用户需要的地图服务。

适配窄屏、安全区、底部导航及软键盘。iOS 日期时间输入用可收缩的栅格、min-width:0、width:100% 和必要的容器限制，实测无横向溢出。提供表单标签、可读对比度和足够大的触控区；操作按钮不与卡片点击冲突。

## 数据与隐私

使用稳定 ID，不能依赖数组下标关联完成状态。分离默认行程和用户覆盖、新增、删除状态，升级默认数据时保留用户修改。每次旅行使用独立存储命名空间和 schemaVersion，避免同一域名不同项目相互覆盖。

持久化前校验日期、时间、结束时间和字段类型；存储不可用或超出配额时提示并保留当前输入。导入 JSON 时先校验应用标识、版本和全部结构，再预览覆盖范围并让用户确认；先备份、后一次性替换，失败不能破坏旧数据。导出包括新增、修改、删除、完成、美食和清单状态。

文本安全渲染，外部链接限制允许的协议，电话字段单独处理。不把护照号、订单凭证、联系方式或截图写进公开仓库。默认说明“本机保存、不会自动跨设备同步”，云同步仅按用户明确要求实现。

## 可选截图识别

需要机票或地图截图识别时，可采用浏览器内 OCR；允许用户手动录入作为回退。首次下载组件可能需要联网，识别失败或字段不确定时提示核对。只把识别结果预填表单，不自动保存；尤其核对航班号、机场、日期、起降时间和时区。仅在实现确实没有传输截图时声明本机识别；第三方脚本、模型下载和图片服务的网络依赖要如实说明。

## 离线安装与更新

提供 manifest、实际尺寸正确的图标和 Service Worker；使用相对资源路径，支持部署在仓库子路径。PWA 安装需要 HTTPS 或受支持的本地开发环境，不能承诺双击 HTML 就能完整离线安装。

核心页面和本地资源预缓存；导航采用联网优先、失败回退缓存。动态资源按需缓存并限制范围，避免缓存凭证。缓存名称含应用前缀与版本，激活时只清理本应用旧缓存，不能删除同域其他 App 的缓存。外部地图、官网、尚未缓存的图片与首次 OCR 下载需要网络。

版本文件、页面版本与缓存版本保持一致；升级保留本机数据，提供手动检查更新，自动刷新前保护未保存表单并避免刷新循环。

## 验证与交付

至少验证：窄屏显示和输入；新增、修改、删除撤销及刷新后保持；跨午夜、跨年与新增旅程外日期；导出后恢复且非法导入无损；首次联网后离线重开；更新后数据保留。OCR、地图等可选功能按实际实现检查。检查 manifest 和资源路径、控制台错误及版本一致性，未实测的能力如实列出。

交付可运行目录与使用方式；用户要求上线时再使用可用部署工具并验证最终地址。安装、发布与访问权限以当前用户授权为准。

## 原始案例

方法来自吉隆坡—新加坡旅行助手。仓库内的 `examples/kl-sg-trip/` 是原项目快照，仅供在可用时参考界面和交互。它含固定年份、月/日索引、特定城市和旧版存储/缓存策略，不直接作为通用模板复制；本 skill 无需加载该示例即可使用。
